# Backend README

## What this backend is

The **backend** is a small FastAPI service that will eventually power the DevMemory AI application.  In this phase we only provide a minimal HTTP API that can be started locally.

## Prerequisites

- Windows PowerShell (the commands below are for PowerShell)
- Python (installed and added to `PATH`)

## Create / Activate the virtual environment

```powershell
cd C:\DevMemoryAI\backend
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

> **Note**: The `Activate.ps1` script sets the environment so that `python` and `pip` point to the isolated virtual environment.

## Install the requirements

```powershell
pip install -r requirements.txt
```

## Run the FastAPI server

```powershell
uvicorn app.main:app --reload
```

- The `--reload` flag restarts the server automatically when you edit code (useful during development).

## Available endpoints

| Method | Path | Description |
|--------|------|-------------|
| GET    | `/`  | Returns a JSON confirming the backend is running |
| GET    | `/health` | Simple health‑check endpoint |
| GET    | `/docs` | Interactive Swagger UI (auto‑generated by FastAPI) |
| GET    | `/redoc` | Alternative ReDoc documentation |

You can open a browser and visit `http://127.0.0.1:8000/docs` to explore the API.
