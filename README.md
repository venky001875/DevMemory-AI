# DevMemory AI

DevMemory AI is a project-aware Generative AI developer memory
and troubleshooting assistant.

## Purpose

DevMemory AI connects a developer's real local project folder
with a local CLI and a remote FastAPI backend.

The system records developer commands, errors and solutions,
then uses Generative AI, semantic search, RAG and persistent
memory to help developers troubleshoot similar problems.
